# Furigana for Spotify — Release package

## English

Requirements: Windows 10/11, Spotify desktop for Windows, and Spicetify available in `PATH`.

1. Extract the ZIP completely.
2. Open PowerShell in the extracted folder.
3. Run:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

To uninstall:

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

The installer preserves an existing installation as a timestamped backup before replacing it.

## 简体中文

需要 Windows 10/11、Windows Spotify 桌面客户端，以及已加入 `PATH` 的 Spicetify。

1. 完整解压 ZIP。
2. 在解压目录中打开 PowerShell。
3. 运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

卸载命令：

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

覆盖安装前，安装器会把现有版本保留为带时间戳的备份。

## 日本語

Windows 10/11、Windows版Spotifyデスクトップアプリ、および `PATH` から実行できるSpicetifyが必要です。

1. ZIPを完全に展開します。
2. 展開したフォルダーでPowerShellを開きます。
3. 次を実行します。

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

アンインストール：

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

上書きインストールの前に、既存バージョンはタイムスタンプ付きのバックアップとして保存されます。
